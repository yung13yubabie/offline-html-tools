# 離線 HTML 工具箱

營業稅、分類帳、PDF 與會計計算機，四個工具各自是一份可以獨立開啟的 HTML。下載需要的那一份即可使用，不必安裝軟體、啟動伺服器或下載整個 Repo。

營業稅工作台已更新至 **v2.14.0**：每期共用備註、關係企業合併付款、每期客戶銷貨收入與通知變數，以及統一的工作台介面。會計計算機更新至 **v1.6.0**，進銷項採精簡冊別摘要與專心模式，並可彙總二／三聯免稅金額，分類帳與 PDF 維持 ui.1 修訂。四個工具都有可拖曳移動的修改標註；`apps/` 內就是可下載後直接離線開啟的新版 HTML。

## 下載與開啟

1. 點上表的 HTML 檔案，進入 Repo 的檔案頁。
2. 使用 GitHub 右上方的 **Download raw file** 按鈕下載該檔案。
3. 保留 `.html` 副檔名，用桌面 Chrome 或 Edge 開啟。

請下載 HTML 原始檔，勿把 GitHub 的檔案檢視網頁另存為 HTML。四個工具都已內嵌需要的程式與樣式，不需另外下載 `feedback/`、`tools/` 或其他同目錄檔案。

## 新版有哪些改變

- **計算機進銷項**：母群組依類型編號，冊別用 1-1、1-2 顯示；主頁保留未稅、稅額、含稅、明細、刪除及新增冊別，其他集中於專心模式。
- **二／三聯免稅金額**：銷項二聯、三聯母群組可填選填免稅金額，與原免稅類型明細加總到上方免稅金額總計。

- **每期共用備註**：每一期設定預設一則，可新增備註 1、2 等；本期工作會顯示共用訊息，通知可插入對應變數。
- **關係企業合併付款**：登記一筆原始付款，逐家公司指定沖款金額，合計必須一致；各公司只計入自己的分配金額，可整筆撤銷。
- **本期銷貨收入**：每期、每位客戶獨立填寫，可從客戶清單或本期工作編輯，通知模板支援 `{銷貨收入}`。
- **全站閱讀層級**：依 UI UX Pro Max 統一字級、間距、表單及明暗狀態；客戶名稱下方改為有標籤的地址、聯絡人、本期記帳費與客戶庫預設費用。

- **營業稅收發票通知**：預設採用本機今天＋1 天，可改＋2、＋3 或其他天數，自動找出本期適用、尚未收齊發票且預約日符合的客戶；單一、合併與 TXT 匯出共用日期條件。
- **營業稅通知模板**：移除親切語氣選擇與未修改的親切內建副本，保留原本模板；使用者修改過的副本會保留為自訂模板。

- **多元一次選單填寫**：選未知數與方程式數量，逐欄填係數、正負號與等號右側數值；即時預覽算式，保留進階文字輸入。
- **比例換算工作表**：選換算方向及「整體為 100%／自訂已知比例」，再依序填已知條件；切換時保留草稿，結果放大顯示。
- **數字池擴充至 100 筆**：加法、減法、加減混合都可輸入 100 筆。小清單保留完整排序搜尋；大清單提供標準與加強搜尋，清楚標示只搜尋部分組合。
- **日期與帳期**：計算兩日期相差幾天，或從指定日期加減天數；可選日曆日或僅排除週末的工作日。
- **五模式工作區**：一般計算、數字池、日期與帳期、稅額試算、勞健保分開操作，保留短過渡動效、窄視窗版面與減少動態效果設定。
- **先前 ui.1 修訂**：四個工具的修改標註入口與面板皆可拖曳，支援位置記憶、鍵盤操作與歸位；PDF、分類帳與營業稅工作台保留先前的版面及操作改善。

四份 HTML 維持獨立離線使用，沒有新增 CDN、外部字體或連網元件。完整說明見 [計算機 v1.5.0](revisions/accounting-calculator-v1.5.0.md) 與 [先前 UI 修訂及設計參考](revisions/ui-floating-review.md)。

## 營業稅每期備註、銷貨收入與合併付款

**共用備註**：開啟「期別管理」→該期設定，預設一則，可新增或移除（最多 20 則，每則 4000 字）。不同期別各自保存；不會覆蓋個別客戶的本期補充事項。通知模板可插入 `{本期共用備註}` 合併帶入，或 `{共用備註1}`、`{共用備註2}` 分別帶入。備註內容中的變數形式文字視為原文，不會再次展開。

**銷貨收入**：在客戶清單的「本期銷貨收入」欄或本期工作費用區填寫，依目前期別保存。允許空白、0 及最多兩位小數；未填與 0 分開顯示，通知模板可插入 `{銷貨收入}`。這是收入資料，不會自動加入應收款、營業稅或記帳費。客戶庫單獨匯出不含各期收入，請使用完整或包含該期工作資料的備份。

**合併付款**：在本期工作的付款區選「登記關係企業合併付款」，選付款公司，填付款日期、原始總額，再逐家公司分配要沖抵的金額。分配合計必須等於原始總額，且不能超過各公司目前尚欠；同一期適用客戶才可選取。款項按各公司的既有沖銷順序處理，不會將整筆總額重複計入每家公司。例：收到甲公司 900 元，分配甲 400、乙 500，總收款仍為 900 元。

合併分項會保留同一筆付款來源；需調整時，先撤銷整筆再重新登記。部分備份若涉及合併付款，會連同必要的關聯公司與期別資料一起匯出；不完整分項無法匯入。若付款會影響已結束後期的承接餘額，須先解鎖受影響期別，儲存後會重新鎖定。

操作、相容性與驗證見 [營業稅 v2.14.0 修訂紀錄](revisions/vat-workbench-v2.14.0.md)；[設計規則與技能來源](design-system/vat-workbench.md)另列。

## 營業稅收發票通知怎麼用

1. 選擇目前期別，進入「通知／模板」的「提醒收發票」。
2. 「本機今天起算，幾天後收發票？」預設為 1，可改成 2、3 等整數（1～3650）。旁邊會顯示目標日期及符合客戶數。
3. 單一客戶清單只列出符合客戶；切換合併通知時先勾選符合名單，可自行取消。預約日不同、本期不適用或已收齊發票的客戶不會列入。
4. TXT 匯出選取收發票模板時，也會篩選並預選符合日期的客戶；同時選其他模板時，這份客戶名單會套用到所有已選模板。

日期依電腦本機日曆起算，包含週末；重新開啟預設回到＋1 天。頁面跨日後，重新聚焦或回到分頁會更新目標日期。沒有符合客戶時，預覽會清空並停用複製；不會代選其他日期的客戶。這個功能不會修改客戶的預約收發票日，也不會自動傳送訊息。

通知分類繼續保留，語氣選單與語氣欄位已移除。舊版原始模板及通知歷史保留；未修改的親切副本會移除，改過內容或名稱的副本保留為自訂模板。若舊版直接將內建原稿換成親切版，未修改的系統內容會還原為原版，已修改內容則保留。詳見 [營業稅 v2.13.0 修訂紀錄](revisions/vat-workbench-v2.13.0.md)。

## 計算機進銷項怎麼用

主頁以發票類型作為母群組；銷項順序為 1 三聯式、2 電子發票、3 二聯式、4 退回／折讓、5 零稅率、6 免稅。進項按既有五種類型依序編為 1～5。這是畫面排序，不是申報代碼；分類名稱完整保留。

展開母群組後，每冊用「類型序號－冊別」顯示，例如 1-1、1-2。主頁只顯示未稅、稅額、含稅與明細、刪除；新增冊別按鈕留在母群組內。冊別刪除後不重用編號，避免同一畫面出現相同識別。

點「明細」進入專心模式，再輸入或編輯每筆資料。用途、逐筆／合計輸入、Enter 方式、新增明細及完整操作說明都在裡面；數字欄不再隨大螢幕無限拉寬。按「確定」、Esc 或背景可回摘要，已輸入資料保留。警示會在明細按鈕顯示 `!`，可直接開啟或用上一／下一筆警示前往。原本大寫、稅率與操作說明保留於可展開的說明區。

銷項三聯、二聯母群組另有「免稅金額」，預設留空，可填 0 或最多兩位小數。上方 **免稅金額總計＝三聯母群組免稅＋二聯母群組免稅＋原「免稅」類型明細**；新增冊別不會重複加計。免稅金額不影響應稅未稅、稅額、含稅或最終稅額。相同金額請選擇適用位置填寫；不要同時在母群組與免稅明細重複記入同一筆。格式錯誤時會提示修正，免稅總計顯示「待修正」。

詳細操作與設計見 [計算機 v1.6.0 修訂紀錄](revisions/accounting-calculator-v1.6.0.md)。計算內容維持本次頁面使用，重新整理會清空。

## 一般計算中的選單式工具

多元一次與比例換算位於一般計算下方，可直接填寫或收合，也可點功能卡跳到對應區塊。

**多元一次方程式**：先選未知數數量與方程式數量，再逐欄選正負號、填係數與等號右側數值。沒填的係數視為 0，右側必填；可載入二元、三元範例。調整數量會保留暫時隱藏的內容，重新整理仍會清空。需要直接貼上算式時，將「填寫方式」改為進階文字輸入。

| 條件 | x 的係數 | y 的係數 | 等號右側 |
| --- | --- | --- | --- |
| 第一條 | ＋ 1 | ＋ 1 | 100 |
| 第二條 | ＋ 2 | ＋ 3 | 240 |

這組條件的結果為 `x = 60、y = 40`。表格最多 10 個未知數、20 條方程式；條件不足、矛盾或無法可靠判定時會提示，不會硬給唯一解。

**比例換算**：先選要算百分比或數值，再選已知基準。「以完整數值為 100%」會固定百分比為 100；「自訂已知比例」可自行填百分比。例如 200 對應 40%，則 100 對應 20%。兩個方向的目標值各自保留，畫面同步顯示對應關係與公式。

兩個功能都在修改條件後清除舊結果。欄位可用有效千分位、小數與科學記號；係數負號由選單選擇，比例百分比欄不用輸入 `%`。詳細規則見 [v1.5.0 修訂紀錄](revisions/accounting-calculator-v1.5.0.md)。

## 數字池怎麼用

1. 開啟會計計算機的「數字池」，填入目標數字。
2. 逐筆輸入數字，名稱可留空；也可貼上多行文字。只有數字時每行一筆，有名稱時選擇分隔符號，例如 `房租｜1200`、`材料｜350`。分隔符號可自行指定。
3. 選擇加法、減法或加減混合，設定允許差額後搜尋。允許差額填 `0` 只找完全符合，留空則包含接近的組合。大清單可選「標準搜尋」或「加強搜尋」。
4. 展開差額群組查看算式與各筆名稱。每組會標出帶正負號的差額：`+1` 表示比目標多 1，`−1` 表示比目標少 1。名稱維持清楚的正文大小，不會被結果數字覆蓋。

| 模式 | 搜尋規則 | 輸入上限 | 完整排序搜尋範圍 |
| --- | --- | --- | --- |
| 加法 | 選出一筆或多筆相加 | 100 筆 | 32 筆以內 |
| 減法 | 選一筆作為起始值，再扣除其他選中的數字；也可只有起始值 | 100 筆 | 28 筆以內 |
| 加減混合 | 每筆可選擇加入、扣除或不使用 | 100 筆 | 20 筆以內 |

每筆在同一組內最多使用一次；相同數字的不同列仍視為不同項目，保留各自名稱。可輸入負數與最多 4 位小數，每個數字及目標的絕對值上限為 1,000,000,000。減去負數依一般數學規則等同加上其絕對值。

**輸入 100 筆**與**顯示最多 100 組結果**是兩個不同限制。在上表完整搜尋範圍內，結果按最接近目標的順序列出；超出範圍時只搜尋部分組合，再依已找到的結果排序。每組算式仍精確核算，但大清單不保證找出全局最接近或所有組合，沒找到也不代表不存在。「加強搜尋」投入較多搜尋資源，仍保留相同限制。

結果按完全符合、差 1、差 2 等差額分組，可展開收合。搜尋在本機執行，可取消；修改目標、清單、強度或搜尋條件後須重新搜尋。可匯出包含算式與原始名稱的 TXT；部分搜尋和結果截斷的說明也會一併匯出。

## 日期與帳期怎麼用

- **日期差**：選擇起日、迄日與計算方式。預設不含起日、包含迄日，可另勾選計入起日；往回計算以負數表示。
- **加減日期**：選擇基準日期，輸入正數往後推、負數往前推；天數必須為整數，範圍為 −100,000 至 +100,000。
- **計算方式**：日曆日計入每一天；工作日只排除週六、週日，**不另扣國定假日，也不納入週末補班日**。

日期預設帶入裝置的本地今日，支援西元 0001～9999 年的有效日期；無效日期或超出範圍的結果會提示修正。這是日期試算，帳期是否含起日、適用假日與實際到期規則仍依使用情境選擇。詳細計算語意見 [v1.4.0 修訂紀錄](revisions/accounting-calculator-v1.4.0.md)。

## 使用修改標註

1. 點「修改標註」，從選單或頁面選擇想調整的區塊。
2. 填寫修正方向，按「儲存標註」。
3. 完成後匯出 JSON 或 TXT，交給維護者處理。

標註入口預設在右下角。拖曳旁邊的點狀把手可移動位置，展開後同樣能移動面板；位置依工具分開記憶。聚焦把手後也可用方向鍵移動，按住 Shift 加速，Home 或面板上的「歸位」可回到右下角。

標註可編輯與刪除，只記錄修改需求，不會自動更改工具或業務資料。標註模式會暫停原頁面操作，離開後恢復；請勿在需求中填入客戶個資、帳號或密碼。詳細行為見 [標註模組說明](feedback/README.md)。

## 更新與備份

更新前，先從舊版匯出業務資料及修改標註，保留舊 HTML，再下載需要更新的工具。以備份副本確認筆數、金額、還原與輸出結果後，再用於日常工作。

瀏覽器儲存不等於備份。更換檔案位置、名稱、瀏覽器，或清除瀏覽器資料，可能影響原本的本機資料讀取；需要時請用工具提供的備份還原。計算機內各模式的計算內容與表單草稿重新整理後會重設，重要結果請先另存。

## 維護與更新紀錄

營業稅的 `vat/` 來源由 `python3 tools/embed-vat.py` 重新內嵌，`--check` 可核對成品一致；使用者不需下載來源檔。

`apps/` 放可直接下載使用的成品；`calculator/`、`feedback/`、`tools/`、`tests/` 用於開發維護，使用者不需安裝。修改 `calculator/` 來源後，執行 `python3 tools/embed-calculator.py` 重新產生計算機 HTML；`--check` 可確認來源與成品一致。數字池核心 `calculator/number-pool.js` 與日期核心 `calculator/date-tools.js` 均已內嵌；數字池透過本機 Blob Worker 搜尋，無須另外下載腳本或連網。標註模組由 `feedback/offline-review.js` 透過 `python3 tools/embed-feedback.py` 內嵌到各 HTML。
