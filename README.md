# 離線 HTML 工具箱

營業稅、分類帳、PDF、會計計算機，四個工具各自是一份獨立 HTML。下載需要的檔案，用桌面 Chrome 或 Edge 開啟即可；不用安裝、啟動伺服器或下載整個 Repo。

營業稅工作台更新至 **v2.17.0**：九個頁面共用新的導覽、配色、表單、頁籤與視窗設計；PDF 改為直接在實際紙張預覽上調整。計算機維持 v1.8.0，其他兩個工具維持 ui.1 修訂。

## 營業稅 v2.17.0：全域重構

- **統一工作流程**：導覽分為每日處理、資料與輸出、管理；九個頁面統一頁面操作列、表單、表格、狀態與對話框，包含明暗模式及窄視窗。
- **本期工作**：客戶清單搭配六個固定頁籤，切換工作不必回到大卡片；目前客戶、期別與儲存按鈕集中在儲存列。地址、聯絡人及費用仍以正常資料字級顯示。
- **設定分類**：收發票、款項提醒、快遞、法規、待辦優先級、畫面偏好分開操作；切換分類保留尚未儲存的輸入，最後按「儲存設定」。
- **完整說明可展開**：收起重複的操作說明，保留原文；日期、金額、狀態、驗證與必要警告直接可見。

本輪實際使用 UI UX Pro Max。可查看 [設計規則與技能來源](design-system/vat-2.17/MASTER.md) 及 [互動線框 HTML](design-system/vat-2.17/wireframes.html)，線框只使用示意資料。

### 直接調整 PDF 紙張

1. 進入「列印編輯」，選擇期別、輸出範圍及方向，中間直接顯示實際 A4 報表。
2. 點選表格欄位或資料區塊。拖曳表頭右側邊線調欄寬；也可按「縮窄／加寬」，或聚焦邊線後按方向鍵。
3. 使用右側工具調整前後順序、靠左／置中／靠右、隱藏；從「欄位與區塊」恢復隱藏項目。復原／重做保留最近 30 次編輯。
4. 按「儲存版面」，再按「列印／PDF」，於系統列印選擇另存 PDF。

預覽立即反映草稿；縮放只改畫面比例，A4 尺寸不變。未儲存時停用列印，切換另一種類或離開會確認是否捨棄。各輸出內容分開記住版面，所有期別共用；原數值設定保留在「進階數值與輸出規則」。列印不包含工具、選取線或拖曳把手。

支援本期總表、前期寄送、客戶基本／單期／年度、狀態、功能區塊、工作待辦及日曆記事。詳見 [v2.17.0 修訂紀錄](revisions/vat-workbench-v2.17.0.md)。

### 本期登記與收款

本期工作保留收發票、建立日期、稅額、跨期、繳納、客戶付款與補充事項的批次入口。勾選客戶後逐家填寫，或套用共用值；視窗顯示各家簡易資料與原值，搜尋不清除勾選和草稿。儲存會更新清單、個別明細、通知及列印使用的同一份資料。

- 空白稅額代表未登記；`0` 與負數留底都算已登記。繳納可勾選多家統一登記日期，各自記錄本期應繳，不會新增客戶匯款。
- 收發票狀態與改期保留歷史；跨期依實際上一期判斷資格。備註預設追加，另可明確取代或清空。
- 每期共用備註預設一則，可新增；通知支援 `{本期共用備註}`、`{共用備註1}` 等。每位客戶每期的銷貨收入獨立保存，支援 `{銷貨收入}`，不自動加入稅額或應收款。
- 關係企業合併付款記錄一筆原始款項，逐家公司指定沖抵金額，分配合計須一致；保留各公司 FIFO 沖款，可整筆撤銷。
- 未勾選客戶不覆寫；無效值、資料衝突或影響已鎖定後期時整批不寫入。已結束期別需先解鎖，成功儲存後重鎖。

批次操作見 [v2.16.0](revisions/vat-workbench-v2.16.0.md)、[v2.15.0](revisions/vat-workbench-v2.15.0.md)；共用備註、收入及合併款見 [v2.14.0](revisions/vat-workbench-v2.14.0.md)。

### 通知

收發票提醒預設本機今天＋1 天，可改＋2、＋3 或其他天數，自動挑出本期適用、未收齊且預約日符合的客戶。單一、合併與 TXT 共用條件；保留原版模板及使用者自訂內容。

批量輸出可篩選日期已建立／未建立、稅額已登記／未登記，並搭配搜尋；提醒收發票的目標日期條件仍會套用。詳見 [通知與日期篩選](revisions/vat-workbench-v2.13.0.md)。

## 計算機 v1.8.0

- 五個模式：一般計算、數字池、日期與帳期、稅額、勞健保。多元一次及比例換算可用選單與欄位填寫，保留進階文字輸入。
- 數字池最多 **100 筆**，可貼入名稱與金額、自訂分隔符號，用加、減或混合尋找目標；完全符合與差額分組展開。大清單採有限搜尋，明示只搜尋部分組合。
- 日期可算相差天數或加減天數；工作日模式只排除週末，不含國定假日表。
- 進銷項以發票類型／冊別整理；專心模式可接續下一冊或選種類。二／三聯逐筆清空稅額可轉免稅，連動免稅合計。
- 覆核只顯示序列、未稅、稅額、含稅及全冊加總；多筆分欄／分頁，點序列編輯。可清除全部計算資料並保留設定與標註。

計算內容及表單草稿重新整理後會重設，重要結果請先另存。完整變更見 [v1.8.0](revisions/accounting-calculator-v1.8.0.md)、[v1.7.0](revisions/accounting-calculator-v1.7.0.md)、[v1.6.0](revisions/accounting-calculator-v1.6.0.md)、[v1.5.0](revisions/accounting-calculator-v1.5.0.md)。

## 修改標註與資料備份

四個工具皆有「修改標註」，入口與面板可拖曳、分別記住位置；把手可用方向鍵、Shift 加速及 Home 歸位。可編輯、刪除、匯出 JSON／TXT，只記錄需求，不會自動改業務資料；標註模式暫停原頁操作。見 [標註模組](feedback/README.md)。

更新前，從舊版匯出業務資料與標註，保留舊 HTML，再下載新版。營業稅可用完整備份換電腦；覆蓋還原前先下載安全備份。瀏覽器儲存不等於備份，變更檔名、位置、瀏覽器或清除資料可能影響讀取，請使用工具的匯出／還原流程。

PDF 家族的既有轉圖擷取頁面內影像，不保證包含文字、向量或完整排版。稅額、保費與勞退仍需依適用身分、年月及主管機關規定核對，健保公司負擔需填實際金額。

## 驗證與維護

**v2.17.0** 已通過本機與 [GitHub CI](https://github.com/yung13yubabie/offline-html-tools/actions/runs/43802636884) 各 **62 組 Chromium 檢查，全數通過**，以及全部既有純回歸與來源內嵌一致檢查；CI 使用 `file://` 直接離線開啟交付 HTML。

本輪驗證紀錄見 [TEST_REPORT.md](TEST_REPORT.md)，含實際 Chromium 流程、合成資料、PDF 文字／頁面邊界與截圖。沒有把未執行的瀏覽器、實體手機或實體印表機測試列為通過。

`apps/` 為可下載成品；`vat/`、`calculator/`、`feedback/`、`tools/`、`tests/` 為維護來源，不需隨 HTML 下載。無 CDN、外部字體或同目錄執行依賴。

```bash
python3 tools/embed-vat.py          # 內嵌營業稅來源
python3 tools/embed-vat.py --check  # 核對成品一致
python3 tools/embed-calculator.py --check
```

變更共用標註模組時，由 `python3 tools/embed-feedback.py` 重新內嵌四份 HTML，再驗證四個工具。本輪只修改營業稅成品，其餘三份 HTML 維持原版。舊版紀錄保留於 [revisions/](revisions/)。
