# 離線 HTML 工具箱

營業稅、分類帳、PDF 與會計計算機，四個工具各自是一份可以獨立開啟的 HTML。下載需要的那一份即可使用，不必安裝軟體、啟動伺服器或下載整個 Repo。

會計計算機已更新至 **v1.3.0**，加入數字池與四模式工作區；其他三個工具維持 UI 修訂 ui.1。四個工具都有可拖曳移動的修改標註。Repo 的 `apps/` 內就是更新後的 HTML，使用方式維持原本的本機離線開啟。

## 下載與開啟

1. 點上表的 HTML 檔案，進入 Repo 的檔案頁。
2. 使用 GitHub 右上方的 **Download raw file** 按鈕下載該檔案。
3. 保留 `.html` 副檔名，用桌面 Chrome 或 Edge 開啟。

請下載 HTML 原始檔，勿把 GitHub 的檔案檢視網頁另存為 HTML。四個工具都已內嵌需要的程式與樣式，不需另外下載 `feedback/`、`tools/` 或其他同目錄檔案。

## 新版有哪些改變

- **會計計算機 v1.3.0**：以一般計算、數字池、稅額試算、勞健保四個模式整理工作區，加入功能說明、操作狀態與短過渡動效；窄視窗改為單欄，支援系統的減少動態效果設定。
- **數字池**：輸入目標數字與候選清單，找出相加、相減或加減混合的組合。結果按完全符合、差 1、差 2 等差額分組，可展開收合；每組先顯示算式，再顯示原本填入的名稱與數字。
- **先前 ui.1 修訂**：四個工具的修改標註入口與面板皆可拖曳，支援位置記憶、鍵盤操作與歸位；PDF、分類帳與營業稅工作台保留先前的版面及操作改善。

四份 HTML 維持獨立離線使用，沒有新增 CDN、外部字體或連網元件。完整說明見 [計算機 v1.3.0](revisions/accounting-calculator-v1.3.0.md) 與 [先前 UI 修訂及設計參考](revisions/ui-floating-review.md)。

## 數字池怎麼用

1. 開啟會計計算機的「數字池」，填入目標數字。
2. 逐筆輸入數字，名稱可留空；也可貼上多行文字。只有數字時每行一筆，有名稱時選擇分隔符號，例如 `房租｜1200`、`材料｜350`。分隔符號可自行指定。
3. 選擇加法、減法或加減混合，設定允許差額後搜尋。允許差額填 `0` 只找完全符合，留空則包含接近的組合。
4. 展開差額群組查看算式與各筆名稱。每組會標出帶正負號的差額：`+1` 表示比目標多 1，`−1` 表示比目標少 1。名稱維持清楚的正文大小，不會被結果數字覆蓋。

| 模式 | 搜尋規則 | 清單上限 |
| --- | --- | --- |
| 加法 | 選出一筆或多筆相加 | 32 筆 |
| 減法 | 選一筆作為起始值，再扣除其他選中的數字；也可只有起始值 | 28 筆 |
| 加減混合 | 每筆可選擇加入、扣除或不使用 | 20 筆 |

每筆在同一組內最多使用一次；相同數字的不同列仍視為不同項目，保留各自名稱。可輸入負數與最多 4 位小數，每個數字及目標的絕對值上限為 1,000,000,000。減去負數依一般數學規則等同加上其絕對值。

結果優先列出最接近目標的 **100 組**，超過時會顯示截斷提示；不能把顯示筆數當作所有組合的總數。搜尋在本機執行，可取消；修改目標、清單或搜尋條件後須重新搜尋，以免沿用舊答案。需要保留結果時，可匯出包含算式與原始名稱的 TXT。

## 使用修改標註

1. 點「修改標註」，從選單或頁面選擇想調整的區塊。
2. 填寫修正方向，按「儲存標註」。
3. 完成後匯出 JSON 或 TXT，交給維護者處理。

標註入口預設在右下角。拖曳旁邊的點狀把手可移動位置，展開後同樣能移動面板；位置依工具分開記憶。聚焦把手後也可用方向鍵移動，按住 Shift 加速，Home 或面板上的「歸位」可回到右下角。

標註可編輯與刪除，只記錄修改需求，不會自動更改工具或業務資料。標註模式會暫停原頁面操作，離開後恢復；請勿在需求中填入客戶個資、帳號或密碼。詳細行為見 [標註模組說明](feedback/README.md)。

## 更新與備份

更新前，先從舊版匯出業務資料及修改標註，保留舊 HTML，再下載需要更新的工具。以備份副本確認筆數、金額、還原與輸出結果後，再用於日常工作。

瀏覽器儲存不等於備份。更換檔案位置、名稱、瀏覽器，或清除瀏覽器資料，可能影響原本的本機資料讀取；需要時請用工具提供的備份還原。計算機的一般算式、批量內容與數字池重新整理後會清空，重要結果請先另存。

## 驗證與使用範圍

v1.3.0 已通過本機 localhost HTTP 的 **43 組 Chromium 檢查**、15 項數字池純邏輯檢查（含 180 組獨立窮舉比對），以及原有純回歸與標註合成檢查。[GitHub CI](https://github.com/yung13yubabie/offline-html-tools/actions/runs/41388709232) 同樣完成 **43 組 `file://` 直接開檔檢查，全數通過**。

先前 ui.1 修訂已通過 [42 組 Chromium file:// 離線檢查](https://github.com/yung13yubabie/offline-html-tools/actions/runs/41373364685)、本機 localhost HTTP 的 42 組檢查，以及既有純回歸與標註合成檢查。這是 ui.1 的歷史紀錄，不包含 v1.3.0 新增的數字池。測試使用人工資料；具體範圍見 [檢查紀錄](TEST_REPORT.md)、[計算機 v1.3.0](revisions/accounting-calculator-v1.3.0.md) 與 [UI 修訂驗證](revisions/ui-floating-review.md)。

- PDF 的既有轉圖功能擷取頁面內影像，可能不包含文字、向量圖或完整排版，不能當作完整頁面渲染。
- 稅額、保費與勞退結果須依身分、適用年月及主管機關規定核對；健保公司負擔需輸入實際金額。
- 已通過的檢查不代表所有 PDF、歷史備份、瀏覽器、大量資料或實際業務情境都已涵蓋。

## 維護與更新紀錄
