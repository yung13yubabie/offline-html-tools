## 內網資料檢索器

在桌面 Chrome 或 Edge 開啟 HTML。Windows 共享資料夾可先貼上完整路徑（如 `\\server\share\資料夾`），按「讀取」後在系統選擇視窗貼上路徑並確認授權。直接選擇資料夾也能搜尋，點選檔案會複製相對路徑。貼上 HTTP(S) 資料夾網址時，內網伺服器需提供可跨來源讀取的目錄清單。

讀取後會展開子資料夾。清單可按檔名、副檔名或所在資料夾排序，並切換升冪和降冪。搜尋可用 `報表 -草稿 -#` 排除關鍵字或符號，用 `-"舊 版本"` 排除含空格的整組文字。`Ctrl+K` 可聚焦搜尋，瀏覽器把 `Ctrl+F5` 交給頁面時也能使用。

點檔名即可複製路徑。「開啟位置」會在瀏覽器新分頁開啟檔案所在的資料夾。本機和 Windows 共享資料夾使用 `file://` 連結，若一開始只用「選擇資料夾」，首次開啟位置時補上根資料夾完整路徑即可。檔名索引留在當前頁面，內網共享資料夾仍需維持內網連線。

**建立日期**可設定起日、迄日或其中一端，包含起迄當天，並可搭配關鍵字。瀏覽器 File API 提供修改日期。要取得 Windows 檔案系統的建立日期，讀取資料夾後按「匯入日期」，展開「Windows 產生日期清單」，把指令貼到 Windows PowerShell 並輸入同一資料夾的完整路徑。回到頁面選取 PowerShell 顯示的 JSON 路徑。沒有日期的檔案在未套用日期篩選時仍會顯示。[File API 規格](https://www.w3.org/TR/FileAPI/#file-section) [Windows 建立時間欄位](https://learn.microsoft.com/en-us/dotnet/api/system.io.filesysteminfo.creationtime)

**資料流向**。本機與 SMB 掃描只列舉名稱及路徑，頁面索引及匯入日期留在記憶體。HTTP(S) 掃描只向輸入網址的同源目錄樹發出請求，不附帶 Cookie 或來源網址。Windows 產生的日期 JSON 留在本機暫存資料夾，內容有根資料夾名稱、相對檔案路徑與日期，用完可刪除。點檔名會寫入系統剪貼簿，路徑可能進入 Windows 剪貼簿歷程或同步。[Microsoft 剪貼簿設定](https://support.microsoft.com/en-us/windows/apps/using-the-clipboard)

## 營業稅 v2.38.1 · 個人房東批量核對

- 在「基本資料」選個人房東，先設定所得人身分及二代健保條件。「每月租金」若有調租，各月以該月的契約金額帶入。設定只用於新給付，不回算已留存的紀錄。
- 在「扣繳核對 → 按合約月租批量帶入」填入各月的實際給付日。一次合付多月或給付總額不同時，改用「新增給付」按該次實際總額記錄，不以月拆算。
- 勾選給付，填實扣後按「核對勾選」；若已確認實扣等於應扣，另有「空白帶入應扣後核對」，不覆蓋已填金額。核對完按「儲存合約」。

## 營業稅 v2.38.0 · 出租方與個人房東扣繳

- 租約基本資料可填租賃地址、出租對象、名稱與聯絡方式。批量建立可共用出租方資料，各據點填自己的地址。續約會帶入這些資料，每期各自保留給付紀錄。
- 出租對象預設為「公司」，沿用租金發票與押金設算核對。選「個人房東」後，從「扣繳核對」新增實際給付日與單次給付總額，兩欄分別比對應扣及實扣金額。可帶入契約月租，一次付多月可直接填合併總額。押金本金另存於「押金紀錄」。
- 供扣繳義務人核對 2021 年起的給付。境內居住者扣繳率為 10%，每次應扣稅額不超過 2,000 元免扣繳。非居住者按 20%。二代健保一般門檻為給付達 20,000 元，按全額計 2.11%，計費基礎上限 1,000 萬元。可依適用資格登記健保免扣取或其他法定門檻。約定代房東負擔且依法應併入租金的費用，請計入給付總額。[各類所得扣繳率標準](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=G0340028) · [健保署補充保費公式](https://www.nhi.gov.tw/ch/cp-3283-34642-2589-1.html) · [健保署代付款說明](https://www.nhi.gov.tw/ch/cp-2828-9345b-3150-1.html)

## 營業稅 v2.37.0 · 續約與資料連結

- 續約表單帶入上期最後一段月租、押金與費用設定。儲存後定位新一期合約，可直接新增調租階段，並從明細往返上期與下一期。舊續約首段留白時，管理合約會帶入可修改的首段月租。
- 案件、單筆合約與批量租約儲存後會展開對應的客戶清單。日曆的合約和調租項目可開啟來源合約。
- 舊紀錄缺客戶或類別時，可在編輯頁重新選擇。遺失上期的合約可確認解除失效連結，保留本期資料。刪除或匯入時仍會檢查案件、合約和續約的關聯。

## 營業稅 v2.36.0 · 押息批量核對

「逐期核對」的租金與押息兩區都可選本期或本年度、全選月份、核對勾選、標記未開與清除核對。兩區各自勾選與處理。

押息「核對勾選」保留已填的實開銷售額，空白帶入當月應列銷售額，略過不計息的月份。缺本金或年度郵政利率時，補齊後即可核對勾選。完成後按「儲存合約」。

## 營業稅 v2.35.0 · 逐月押金設算利息核對

「逐期核對」的押金區按月帶入「押金紀錄」的設算利息與應列銷售額，採用該月所屬年度的郵政利率。可按月設定是否計息、登記發票狀態及實開銷售額。本期合計加總各月金額，通知也帶入對應月份。舊版整期押息可在同頁展開查看。

## 營業稅 v2.34.0 · 逐月租金與批量核對

「管理合約 → 逐期核對」按月顯示應開、實開與差額。「顯示與輸入」可切換未稅或含稅，原先輸入的金額及基準會保留。「每月租金」可設定換算用的租金稅率，預設 5%。

可逐月輸入，或切換到本年度後同時勾選多月。「核對勾選」保留已填實開金額，空白月份帶入應開金額。另可標記未開或清除核對。完成後按「儲存合約」。舊版整期租金紀錄仍可展開查看，有登記單月時，通知依單月資料產生。

## 營業稅 v2.33.0 · 分段調租提醒

在「管理合約 → 每月租金」可逐段設定調租提醒。預設提前 30 天，可改為 0 至 365 天，或關閉該段提醒。0 天表示在生效日提醒。

展開合約列即可查看調漲或調降的生效日、原月租、新月租與差額。日曆標示調租生效日與啟用的提醒日。「今日待辦」從提醒日顯示到生效日，確認後即收起。改動生效日、租金或提醒天數會重新排程。

## 營業稅 v2.32.0 · 案件進度、押金試算與列印

案件可分批新增進度紀錄，每筆包含日期、階段與選填說明。清單顯示最近進度，展開可查看歷次紀錄。

新增租約時會用開始日期所在年度即時試算。在管理合約的「押金紀錄」可切換年度查看每月設算利息和應列銷售額。每月設算利息為押金乘該年 1 月 1 日的郵政一年期固定利率再除以 12。一般稅額的銷售額再除以「1＋徵收率」，查定計算使用設算利息。缺少利率時可在同頁補填。逐期核對仍按該期的計息月數計算及取到分。[營業稅法施行細則第 24 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=G0340081&flno=24)

「列印編輯」選擇案件或租約與合約，即可預覽各自的清單，並按客戶篩選。新增紀錄儲存後會出現在對應清單，兩種報表的欄位與版面分開儲存。

## 營業稅 v2.31.0 · 每月租金與押金紀錄

新增與管理租約時可分開填寫月租和押金本金。「每月租金」保留分段調租與含稅／未稅設定，「押金紀錄」設定本金、設算利息方式與年度郵政固定利率。無押金填 0，空白表示待填。

在「基本資料」選擇發票核對週期。雙月、季度或年度核對可展開各月租金。押金本金與設算利息顯示在租金旁的獨立核對區。

## 營業稅 v2.30.0 · 日曆記事

月曆、記事清單與當日明細共用事件來源篩選，可與客戶、關鍵字和日期區間併用。單日事件較多時顯示分類筆數，點日期查看當日完整清單。清單預設從早到晚，同一天依時間排序，未指定時間排在最後。「更多操作」可查看操作紀錄或選擇月份清理手動記事。

## 營業稅 v2.29.0 · 本期工作與輸出

本期工作用摘要列顯示期別日期與共用備註，統一從「批次作業」進入批次登記。左側提供快捷篩選，客戶工作依收發票與補充事項、稅額與款項（含跨期）、繳稅登記、收款與沖銷四步驟處理。

帳務「結案檢核」會顯示待補筆數，欠缺文件可逐筆標記已補。客戶庫的銷貨收入靠右顯示，仍可點金額編輯，寄送設定在選自訂來源時才展開實際地址或收件人。

通知批量輸出可依日期、稅額與繳稅狀態交叉篩選，再一鍵勾選符合的客戶。提醒設定可查看各類型的模板與時機。列印預設提供 A4 橫式，金額欄預設靠右，可直接點紙張調整，欄位清單則提供勾選及排序。

## 營業稅 v2.28.0 · 合約管理與批量新增

「管理合約」集中基本資料、租金與押息、逐期核對與通知紀錄。點合約列可展開時間軸。年度郵政利率移到頁首「設定」，逐期核對仍可補填缺少的利率。通知可複製，也可按「存入紀錄」留存在該筆合約，隨合約匯出備份。

從頁首或客戶群組的「批量新增租約」進入。選好客戶和類別後，共用核對週期、租金基準、押息計算方式與提前提醒月數，每列可個別填寫名稱、租期、月租及押金。確認建立時會檢查全部列，修正錯誤後可從原表單重送。

## 營業稅 v2.27.0 · 案件與合約

點案件或合約的統計卡可按狀態篩選。再點一次可回到原本的預設範圍。卡片數量會跟著搜尋與其他篩選條件更新。

展開明細後，日期依實際時間排列，同一天也會按時間排序。編輯彈窗選擇客戶時顯示名稱及代號，聯絡資訊可在客戶群組查看。勾選提醒才會顯示相關欄位。案件、合約、待辦與日曆的測試資料統一由頁面上的「樣本模式」識別。

## 營業稅 v2.26.0 · 今日待辦

工作待辦的新增與列印放在標題列。橫向頁籤下方是案件提醒和合約到期待辦，桌面等寬等高，窄版改為上下排列。案件用兩欄列示客戶與案由，合約依客戶分組，保留到期日、查看及打勾完成。

全站頂欄可從「找客戶」或 Ctrl／⌘ + K 快速跳轉。本期有工作紀錄時進入該客戶的本期工作，其餘可開啟客戶資料。期別欄在手機獨立一列。樣本入口和頁面操作集中在同一區，案件與合約的篩選列減少外框。

## 營業稅 v2.25.0 · 測試樣本

各頁標題旁的「測試樣本」會在新分頁開到同一頁。少量、中量、大量分別填入 6、30、120 位虛構客戶，以及待辦、文件、收款、期別、案件、合約、通知與日曆等關聯紀錄。

樣本分頁可切換資料量，並沿用樣本的明暗設定和標註。「修改標註」可記下版面意見並匯出 TXT 或 JSON。切換份量、重新整理或退出會重新建立或結束該次樣本，正式分頁可繼續使用。樣本備份會加上識別，供樣本模式匯入。

## 營業稅 v2.24.1 · 月租欄位

新增或編輯租約時，可在起訖日期下方填寫月租與含稅／未稅基準。儲存後，合約清單會顯示適用金額。進入「租金與押息」會先看到租金設定，並可增加後續調租階段。

## 營業稅 v2.24.0 · 租約金額核對

案件與合約展開後以日期軸顯示開始、提醒與截止或到期日，並保留備註、待辦和日曆操作。手機採直向日期軸，減少動態模式會直接呈現明細。

租約的「租金與押息」可設定押金、分段月租與核對週期，按年度帶入郵政固定利率。逐期並列應開與實開金額，並可用核對資料產生漏開發票、租金差異和押金設算利息通知。[操作與計算基準](revisions/vat-workbench-v2.24.0.md)

## 計算機 v1.9.0：分攤與多組拆稅

「金額分攤」輸入總金額及日期區間，預設按年分組，也可按月；起日、迄日都計入，依整段區間實際天數分攤。閏年、跨月會自動計算，金額尾差按餘數分配，合計與原輸入一致。

預設輸出為金額與比例，例如 `1,000×122/365`；關閉金額後只剩 `122/365`。日期與分攤結果可另外勾選加入輸出，複製內容也會依選項調整。

「清除計算資料」會一併清除新功能的輸入與結果，保留分組、輸出與稅率設定。計算內容不持久保存，重新整理前請先複製需要的結果。詳見 [計算機修訂紀錄](revisions/accounting-calculator-v1.9.0.md)。

## 營業稅 v2.18.0：跨期聯動

| 延續事項 | 下期操作後，上期如何更新 |
| --- | --- |
| 款項／歷史尚欠 | 按實際已保存沖銷更新「截至目前尚欠」，保留原期末餘款與收款歸期；刪除或撤銷後期付款會恢復尚欠。 |
| 欠缺文件／待歸資料 | 同一來源的完成、重新待補／待處理同步至各期；各期名稱、備註及排程保留。 |
| 跨期發票 | 在本期工作 → 跨期事項，逐批勾選較早期來源並儲存；來源期顯示已處理及處理期別，可取消單批。 |
| 全期待辦／完成日曆 | 同一延續事項在全部期別只列一次；各期仍能查看自己的副本與原排程。 |

例如上期尚欠 100、下期付款沖清後，上期會顯示「原期末 100／後期已沖抵 100／目前尚欠 0」；更後期新產生的費用仍屬更後期。通知、篩選、清單及 PDF 會讀取目前進度，原始付款不會移期或重複新增。

已結束的來源期可接收同一事項的聯動進度，期別維持已結束；直接編輯該期仍需解鎖。每期稅額、繳納、銷貨收入、共用備註與整期帳務完成各自記錄；補件完成後仍可另外標記整期帳務完成。

舊版完成狀態有分歧、來源不明或重複時，會顯示待核對。帳務頁可由開啟的期別選定共同狀態；結構重複需先核對明細，不會按時間戳猜測。刪除當期副本會保留其他期別的同一來源資料，已排除的副本不會在重載後再生。

部分備份會一併包含跨期來源、後期付款、操作來源與合併款的必要關聯資料。詳見 [操作與相容性](revisions/vat-workbench-v2.18.0.md) 及 [資料關聯設計](design-system/vat-2.18-cross-period.md)。

### 直接調整 PDF 紙張

1. 進入「列印編輯」，選擇期別、輸出範圍及方向，中間直接顯示實際 A4 報表。
2. 點選表格欄位或資料區塊。拖曳表頭右側邊線調欄寬；也可按「縮窄／加寬」，或聚焦邊線後按方向鍵。
3. 使用右側工具調整前後順序、靠左／置中／靠右、隱藏；從「欄位與區塊」恢復隱藏項目。復原／重做保留最近 30 次編輯。
4. 按「儲存版面」，再按「列印／PDF」，於系統列印選擇另存 PDF。

預覽立即反映草稿；縮放只改畫面比例，A4 尺寸不變。未儲存時停用列印，切換另一種類或離開會確認是否捨棄。各輸出內容分開記住版面，所有期別共用；原數值設定保留在「進階數值與輸出規則」。列印不包含工具、選取線或拖曳把手。

支援本期總表、前期寄送、客戶基本／單期／年度、狀態、功能區塊、工作待辦及日曆記事。詳見 [v2.17.0 修訂紀錄](revisions/vat-workbench-v2.17.0.md)。

### 本期登記與收款

本期工作保留收發票、建立日期、稅額、跨期、繳納、客戶付款與補充事項的批次入口。勾選客戶後逐家填寫，或套用共用值；視窗顯示各家簡易資料與原值，搜尋不清除勾選和草稿。儲存會更新清單、個別明細、通知及列印使用的同一份資料。

- 空白稅額代表未登記；`0` 與負數留底都算已登記。繳納可勾選多家統一登記日期，各自記錄本期應繳，不會新增客戶匯款。
- 收發票狀態與改期保留歷史；跨期依實際上一期判斷資格。備註預設追加，另可明確取代或清空。
- 每期共用備註預設一則，可新增；通知支援 `{本期共用備註}`、`{共用備註1}` 等。每位客戶每期的銷貨收入獨立保存，支援 `{銷貨收入}`，不自動加入稅額或應收款。
- 關係企業合併付款記錄一筆原始款項，逐家公司指定沖抵金額，分配合計須一致；保留各公司 FIFO 沖款，可整筆撤銷。
- 未勾選客戶不覆寫；無效值、資料衝突或影響已鎖定後期時整批不寫入。已結束期別需先解鎖，成功儲存後重鎖。

批次操作見 [v2.16.0](revisions/vat-workbench-v2.16.0.md)、[v2.15.0](revisions/vat-workbench-v2.15.0.md)；共用備註、收入及合併款見 [v2.14.0](revisions/vat-workbench-v2.14.0.md)。

## 修改標註與資料備份

原有四個帳務／PDF 工具皆有「修改標註」，入口與面板可拖曳、分別記住位置；把手可用方向鍵、Shift 加速及 Home 歸位。可編輯、刪除、匯出 JSON／TXT，只記錄需求，不會自動改業務資料；標註模式暫停原頁操作。見 [標註模組](feedback/README.md)。

PDF 家族的既有轉圖擷取頁面內影像，不保證包含文字、向量或完整排版。稅額、保費與勞退仍需依適用身分、年月及主管機關規定核對，健保公司負擔需填實際金額。

`apps/` 為可下載成品；`vat/`、`calculator/`、`feedback/`、`tools/`、`tests/` 為維護來源，不需隨 HTML 下載。無 CDN、外部字體或同目錄執行依賴。

```bash
python3 tools/embed-vat.py          # 內嵌營業稅來源
python3 tools/embed-vat.py --check  # 核對成品一致
python3 tools/embed-calculator.py --check
```

變更共用標註模組時，由 `python3 tools/embed-feedback.py` 重新內嵌四份 HTML，再驗證四個工具。舊版紀錄保留於 [revisions/](revisions/)。
