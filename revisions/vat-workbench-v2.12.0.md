# 營業稅工作台 v2.12.0

日期：2026-10-31。本次只更新營業稅 HTML 及必要測試／說明，計算機、分類帳及 PDF 工具的 HTML 未變更。資料庫名稱／版本、備份結構版本維持原設定。

## 六項需求

1. **本期共同日期**：最晚匯款、最晚寄出及法定繳款日期獨立顯示，區分日期值、已設定／待設定與說明；沒有新增未經確認的逾期判斷。
2. **儲存位置**：單一儲存按鈕移到所選客戶名稱與記帳費旁，沿用原事件及鎖定規則；無客戶、換客戶、已結束期別與解鎖後儲存皆有檢查。
3. **明細閱讀層級**：子層標題加強字級與字重，說明文字另成較輕層級。
4. **帳款統計**：桌面四張卡片平均分成一列；較窄視窗改兩欄或一欄，避免為維持單列而把字縮小。
5. **通知分類及語氣**：營業稅下分詢問收發票、提醒收發票、最後寄出提醒、匯款提醒、最後匯款提醒；帳務下有缺件通知。新增六個親切專業版內建模板。舊內容、ID、歷史及自訂模板保留，舊版有明確標示；更改語氣標籤不會擅自重寫內容。缺件資料取自實際待補清單。
6. **儲存後的列印版面**：在「列印與 PDF」右側切換「輸出規則／版面調整」，可調整現有欄位／區塊的顯示、順序、相對欄寬、對齊、字級、間距及換行。不同輸出格式各自儲存，同一格式由所有期別共用。

## 版面使用步驟

1. 選擇輸出範圍、期別及客戶等條件。
2. 切到「版面調整」，勾選要顯示的欄位或區塊，以箭頭調整順序，設定相對寬度與顯示方式。
3. 按 **儲存版面**，等候顯示儲存成功。
4. 按 **預覽已儲存版面** 或 **輸出 A4 PDF**。有未儲存變更時會阻止輸出，避免草稿混入結果。
5. 「恢復預設（待儲存）」只重設目前輸出格式的草稿；按儲存才生效，不清除其他格式。

切換輸出種類或離開頁面會結束尚未儲存的調整，請先儲存。紙張方向仍由原輸出規則控制，原待辦列印沿用其既有橫式規則。手機預覽保留 A4 寬度，以左右捲動查看，不把紙張內容擠成另一種版面。

版面設定納入完整備份；舊資料沒有版面設定時採預設。此功能不包含任意拖曳設計、任意新增公式欄或第三方 PDF 引擎。

## 範圍限制

驗證是在 Chromium 的 file:// 環境及人工資料完成，不是實體印表機、所有瀏覽器、所有歷史備份或超大量長文的完整認證；四份代表 PDF 皆一頁，不代表所有多頁分頁組合均驗證。請先匯出完整備份，再以副本試用新版。
