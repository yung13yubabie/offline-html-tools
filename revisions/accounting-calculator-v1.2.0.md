# 會計計算機 v1.2.0

日期：2026-10-31。本次只更新 `apps/accounting-calculator.html` 及必要測試／說明；營業稅、分類帳、PDF 三個 HTML 的檔案雜湊保持不變。

## 七項需求對照

1. **批量計算**：保留原批量功能，加入兩個可展開區塊。
   - 多元一次方程式：一行一條，例如 `x+y=100`、`2x+3y=240`，結果為 x=60、y=40。
   - 比例換算：已知 X 對應 p%，可由 N 求百分比，或由目標百分比反求數值；例如 200 對應 40%，100 就對應 20%。
2. **頂端說明**：移除擠在一起的技術宣傳，保留「計算內容重新整理後會清空」提醒；修改標註另有本機儲存，不在此清空說明範圍。
3. **銷項標題／金額**：統一閱讀層級，調整字級及分行。
4. **進項標題／金額**：同樣處理長標題與控制項，保留原憑證分類。
5. **銷項明細**：國字大寫移到獨立整行，數字加大加粗，拾／佰／仟等位數與數字區分；顯示「先輸入：未稅金額／含稅金額／稅額」，Enter 的移動方式改用文字。
6. **進項明細**：套用相同閱讀與輸入說明，不改原計算及鍵盤移動規則。
7. **投保級距說明**：改成直接說明操作與適用對象，細節可展開；保留適用限制、日期、費率資料與來源資訊，並修正手機頁面被費用表撐寬的問題。

## 方程式與比例的界線

- 最多 10 個未知數、20 條式子、6000 字；變數以英文字母開頭，大小寫有別。
- 支援一次式、小數、正負號、括號及乘除常數。不支援二次式、未知數相乘或除以未知數。
- 分開提示唯一解、多組解／條件不足、無解及數值精度不足。這是有限精度數值計算，不是符號精確運算；小數最多顯示 12 位有效數字。
- 數值超出可可靠處理的範圍時拒絕或提示不確定，避免把運算下溢等錯誤當成零解。
- 比例的已知 X 不可為零；反向求數值時已知百分比 p 也不可為零。目標值為零仍可正常計算。
- 修改任何相關輸入或切換方向會清除舊結果，避免沿用過期答案。
