# 營業稅工作台 v2.23.0

## 帳務處理

本期摘要保留四項數字，客戶清單可按名稱、代號和帳務狀態篩選。客戶明細固定顯示名稱、代號與狀態，總覽、帳務完成、欠缺文件和待歸資料可直接切換。篩選客戶或切換同一位客戶的工作區時保留已勾選的明細。更換客戶時以該客戶的資料重新開始勾選。

批量動作旁會顯示已選筆數。跨期來源與狀態仍可從明細查看，已結束期別沿用原有的唯讀控制。

## 通知模板

模板管理、提醒設定、批量輸出各自顯示對應的控制項。桌面通知庫集中分類、通知類型與模板，編輯區並排顯示模板原文與可編輯的通知預覽。手機上可展開通知庫與客戶清單，選好後回到目前工作區。

模板名稱、原文與啟用設定的草稿按模板暫存在目前分頁，並以「未儲存」提示。可用「儲存模板」寫入資料，或從「更多」捨棄草稿。提醒表單切換日期方式以及新增、移除時間時保留其他輸入，驗證訊息顯示在表單內。

批量輸出以核取方塊選客戶，日期與稅額篩選旁即時顯示人數。選用收發票提醒時，可在輸出區直接調整目標日期。輸出前可核對已選模板、客戶人數及預計產生的 TXT。

版面採用 UI UX Pro Max 的高密度工作區、漸進揭露與鍵盤焦點建議，延續案件與合約的控制高度、色彩與分隔線。資料庫第 6 版與備份第 10 版沿用。測試詳見 [驗證紀錄](../TEST_REPORT.md)。
