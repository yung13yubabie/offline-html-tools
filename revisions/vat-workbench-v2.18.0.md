# 營業稅工作台 v2.18.0

日期：2026-11-17。下期處理同一來源事項時，聯動顯示上期進度；保留每期原始金額、付款歸屬與個別文字。

## 款項

依已保存的沖銷明細追溯原應收項目。本期工作、客戶卡片、尚欠篩選、待辦、通知及 PDF 顯示「截至目前」餘款，付款區同時保留原期末尚欠、後期已沖抵及明細來源。年度表保留期末餘款，另列目前尚欠。

例：第一期應收 100，第二期付款 100 全沖第一期，第三期新增費用 80；第一期目前尚欠為 0，第三期的 80 不會回算成第一期欠款。第一期原期末仍為 100，收款仍在第二期。刪除付款或撤銷整筆合併款，相關來源會恢復尚欠；未沖抵餘款不當作其他來源已付款。

原 FIFO、已保存 allocation、付款前後快照及承接餘額仍供財務寫入使用。發現沖款來源衝突時保留可核對的餘款並顯示提示，不將不明付款當作已沖清。

## 帳務

欠缺文件與待歸資料依「客戶＋種類＋原來源期＋lineage root」識別同一事項。同來源在任何開啟期別標記完成或重新待補／待處理，會在同一交易同步各期 status、完成時間與相關提醒旗標。各期名稱、原備註、預計日期與排程保持原資料，不靠同名或同額合併。

補件為零後具備整期帳務完成資格，仍由使用者另外確認整期完成；重新待補會取消不再成立的整期完成狀態。刪除本期副本只留下該期排除紀錄，其他副本保留；重載不會復活。原來源期刪除後，後期仍保留來源識別。

全部期別的工作待辦只顯示一個同來源事項，優先目前開啟期，否則最近開啟期；同名手動待辦仍是不同 ID。相同來源、相同完成時間的日曆完成事件只列一次，並導向操作期；各期原計畫事件保留。

舊副本在可證實未動的條件下收斂；人工改過或完成時間／版本互相矛盾時保留待核對，可從開啟期別選定共同狀態。重複來源需先回明細核對及移除重複項目，單純切換狀態不能消除結構重複。

帳務編輯／批次新增改為保留草稿的儲存視窗；驗證或寫入失敗不吞內容。已結束期別的直接編輯維持鎖定，後期合法處理只同步來源的衍生進度，不解鎖原期或修改金額。

## 發票

本期工作 → 跨期事項列出同客戶較早期的跨期發票，可逐批選取「已確認拿出／處理」並儲存。完成項目可展開取消。來源期保留當初跨期旗標，顯示後期處理結果，連動清單、待辦、統計與 PDF。

來源以明確 PC ID 固定；之後補建中間期別，既有完成不會改綁。連續多期各自跨期代表不同批次，不能由一次勾選一併清空。舊上期已處理布林僅在來源唯一可核對時承接；來源缺席或候選重複會待核對。批次入口使用相同固定來源規則。

收件已收齊、跨期發票已處理與稅款已繳分別記錄。上期留底仍供參考，不由此新增自動抵稅規則；各期銷貨收入、備註及整期工作完成仍按原期別保存。

## 儲存與備份

共同交易在寫入前讀取 DB 最新資料，核對獨立 baseline 與共享狀態版本；一般單筆、今日待辦、批次、合併款及寄送入口均接入。未編輯共享狀態的舊工作草稿會保留 DB 新進度；明確改狀態卻使用過時版本時拒絕並保留草稿。任何一筆寫入失敗，原操作與聯動資料一起回復。

部分備份依來源圖補齊帳務同來源、發票來源／處理期、後期付款、操作期及合併款分項；必要關聯可能超過原選取期別。來源已真正刪除時保留識別資訊，不虛構資料。備份不包含尚未儲存的發票操作命令。

DB 3、備份格式 7、PDF 版面格式 1 維持；新增來源及版本欄位為可選資料。舊備份可匯入，不明舊狀態先核對。四個工具仍各自獨立離線；此輪只修改營業稅 HTML。
