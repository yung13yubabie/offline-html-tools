# 營業稅工作台 v2.19.0

新增案件頁，以 clientId 引用客戶庫，聯絡資料隨客戶庫更新。案件有待處理、進行中、完成、取消四種狀態，並可填開始／截止日期、時間、備註及提醒。預設為進行中，開始日期採本機日期。

## 日曆與提醒

案件直接投影到日曆，不建立額外 calendarNotes。原訂開始／截止與實際完成日期有各自標示。提醒日與排程日不同時，日曆分開顯示，點選任一項都回到同一案件。沒有截止日期的案件不會被判為逾期。提醒只在案件仍進行、已啟用提醒且時間到達時出現，確認提醒不等於完成案件；調整時間或重新開啟已結案件會重新啟用追蹤。

提醒是 HTML 開啟時的應用內功能，不含背景系統推播。多個分頁同時修改案件時，整筆原始基準與 revision 會比對，過時儲存會被拒絕並保留編輯內容。

## 資料相容性

- DB_NAME 保留 VAT_WORKBENCH_DB，DB_VERSION 由 3 升至 4，只新增 cases。
- cases 紀錄 version 1，以客戶 ID 引用主檔，完成／取消案件仍保留引用。
- BACKUP_VERSION 由 7 升至 8，舊 1–7 仍可讀取；舊版 HTML 會拒絕新格式，避免忽略案件資料。
- 完整備份含案件；案件及日曆部分匯出包含案件與必要客戶，客戶範圍匯出包含其案件。
- 合併缺少 cases 的舊備份保留現有案件；完整覆蓋缺少 cases 的舊備份清空案件，覆蓋前仍要求下載安全備份。
- 刪除客戶、案件寫入與還原會在同一交易驗證最終引用，缺少客戶時整批取消。

## 介面

依 UI UX Pro Max 的資料密集工作台、表單標籤及驗證建議，沿用現有導覽與色彩規格。主要介面只留案件、進度、日期與動作；操作補充收入展開說明。設計與互動線框見 [設計資料](../design-system/cases-calculator-2026-11/MASTER.md)。
