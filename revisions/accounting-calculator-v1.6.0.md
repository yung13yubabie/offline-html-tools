# 會計計算機 v1.6.0

日期：2026-11-12。進銷項主頁改為精簡冊別摘要，輸入與設定集中到較窄的專心模式；銷項二聯、三聯母群組新增選填免稅金額。

## 母群組與冊別

保留完整發票類型名稱與原順序，新增畫面序號：銷項三聯式 1、電子發票 2、二聯式 3、退回／折讓 4、零稅率 5、免稅 6；進項既有五種類型編為 1～5。畫面序號不是官方申報代碼。

原本「統一發票扣抵聯-1」等重複標題改為「1-1」，同類新增冊別為 1-2、1-3。刪除冊別後編號不重用。主頁保留未稅、稅額、含稅、明細、刪除；新增冊別仍在母群組內。零稅率／免稅的摘要顯示金額、稅額 0 及相同含稅金額，明細仍用其原本金額欄填寫。

用途、逐筆／合計輸入、Enter 設定、新增明細、大寫金額、警示詳情及完整操作說明保留在專心模式。文字以短提示搭配可展開完整說明呈現，不刪除原本內容或縮成難讀的小字。

## 專心模式

點「明細」或冊別編號開啟；桌面面板寬度最多 800px，金額輸入欄最多 220px，避免橫跨整個畫面。手機將未稅、稅額、含稅垂直對齊，保留可讀字級與鍵盤焦點。確認、Esc 或點背景可回摘要，計算內容保留；重新整理頁面仍會清空。

逐筆／合計、用途、Enter 導向及原有計算邏輯沿用。合計模式保留張數，已有資料時仍不能直接切換輸入模式。修改值的重算／保留選擇與警示仍可使用。

警示以明細按鈕的 `!`、完整滑鼠提示及輔助名稱呈現；上一／下一筆警示會開啟正確冊別。修正主頁隱藏輸入欄後，警示原本無法聚焦，以及變更視窗大小或切換進銷項可能自行重開舊冊別的狀態問題。開啟與返回的延遲聚焦也會檢查當前操作，避免搶走已開始編輯的欄位。

介面依 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的可讀性、輸入標籤、範圍限制、非單靠顏色傳達狀態與減少動態規則設計，使用原生 HTML／CSS／JavaScript，沒有外部字體或執行依賴。

## 二／三聯免稅金額

僅銷項三聯、二聯母群組提供選填欄位，預設空白，可填 0、有千分位與最多兩位小數；單欄上限 999,999,999,999.99。空白不會自動填成 0，清空會撤回該欄貢獻。

免稅金額總計加總兩個母群組欄位及原「免稅」類型明細。母群組金額不隨冊別數量重複加計，也不加入應稅未稅、稅額、含稅或最終稅額。不同位置代表額外錄入的金額，沒有自動判斷相同憑證的功能；同一筆免稅銷售請勿重複輸入。

無效或負數金額會在欄位旁提示，免稅合計顯示待修正；應稅數值不受影響。有效新欄位以整數分加總，避免 0.1＋0.2 的浮點殘差。原本發票明細的金額輸入及格式化規則保持。
