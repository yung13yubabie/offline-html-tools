# 會計計算機 v1.9.1

「金額分攤」的起始與結束日期可手打、貼上或用日曆挑選。手打格式有西元 `YYYY/MM/DD`、`YYYY-MM-DD`、`YYYYMMDD`，前兩種允許月份與日期省略前導零。無效日期和結束日早於起始日會在日期欄提示。

填妥日期與總金額後立即試算。修改任一條件時先清除舊結果，再自動更新，避免複製錯的期間。年／月分組都含起訖，以整段實際天數為分母，各組精確分配到分並維持合計。

UI 採上方輸入、下方明細，桌面起訖日期等寬並排，手機逐欄排列。明細每組顯示實際起訖日，算式及複製預設為金額乘日數比例，可另外勾選資料。設計沿用 UI UX Pro Max 的欄位標籤、就地驗證和可見焦點規則。

交付成品為 [會計計算機 HTML](../apps/accounting-calculator.html)，可離線單檔使用。[測試紀錄](../TEST_REPORT.md)
