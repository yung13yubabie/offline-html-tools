# 會計計算機 v1.8.0

日期：2026-11-12。新增全面清除計算資料、專心模式切冊，以及不用捲動的窄幅分頁覆核與全冊加總。

## 清除計算資料

頂端按「清除計算資料」，確認後原頁清空，不需重新整理。取消不會改動資料。

清除範圍包含單次算式與記憶值、批量與小計算機、方程式的表格與文字草稿（含縮小後隱藏的係數）、比例兩個方向的草稿、數字池清單／貼上原文／目標／結果、日期條件與結果、各冊進銷項明細與留抵，以及勞健保的薪資與帳單金額。數字池正在執行的 Worker 會停止，舊結果無法回填。

稅率、預設欄位、Enter 設定、既有冊別及其用途／輸入模式、複製偏好、工具選項、費率與眷屬選項保留。各冊留下單一空白列；數字池保留模式、允許差額、搜尋強度及分隔符號。修改標註與浮動位置不會清除。

## 在專心模式切冊

上方選「種類」及「冊別」，按「前往」即可進入既有冊；冊別選「新增冊別」則建立該種類的新冊。種類按銷項、進項分組，完整分類名稱保留。

「下一冊」前往目前種類中實際存在的下一冊；已到最後就新增一冊。先改選種類時，會前往該種類第一冊；若該種類沒有冊別則新增。切換後仍為專心模式，原冊資料和選項保留，手機會將預設輸入欄位移到可見範圍。

## 覆核與全冊加總

維持序列、未稅、稅額、含稅四欄與點序列回到原筆編輯。少筆使用窄幅表格，桌面多筆分成兩個窄欄；每頁筆數依螢幕大小及全冊最長金額安排，避免後頁才出現長金額而改動分頁容量。

容量不足使用「上一頁／下一頁」，不要求捲動，也不縮小字體硬塞。旋轉或調整視窗會重新安排容量；空冊仍顯示四欄、共 0 筆與零值加總。尾端未登打的空白列不列入。

底部固定「全冊加總」的未稅、稅額、含稅，包含該冊全部頁面，不是僅加總當前頁。免稅稅額在覆核以 0 顯示；零稅率及原免稅簡式類型為金額／0／金額。覆核不重算、複製或新增明細。
